# yt-dlp GUI

Легковесная графическая оболочка для [yt-dlp](https://github.com/yt-dlp/yt-dlp), позволяющая скачивать видео и аудио без командной строки.

## Возможности

- скачивание видео в лучшем качестве или с ограничением до 2160p/1440p/1080p/720p/480p;
- извлечение аудио в MP3, M4A, Opus, WAV или FLAC;
- выбор папки сохранения и пути к `yt-dlp`;
- загрузка одиночного видео или плейлиста;
- отображение прогресса и журнала работы;
- отмена текущей загрузки;
- сохранение настроек между запусками.

Интерфейс написан на Python и Tkinter. Сторонние Python-пакеты не требуются.

## Требования

- Python 3.9 или новее;
- [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases/latest);
- [FFmpeg](https://ffmpeg.org/download.html) — нужен для объединения видео с аудио и конвертации аудиофайлов.

## Установка

```bash
git clone https://github.com/talex00/yt-dlp-gui.git
cd yt-dlp-gui
```

Скачайте `yt-dlp.exe` и положите его рядом с `app.py`. Альтернативно установите `yt-dlp` в `PATH` или выберите исполняемый файл в интерфейсе.

Убедитесь, что `ffmpeg` и `ffprobe` доступны через `PATH` или лежат рядом с `yt-dlp.exe`.

## Запуск

```bash
python app.py
```

1. Вставьте ссылку на видео или плейлист.
2. Выберите видео или аудио и нужное качество/формат.
3. Укажите папку сохранения.
4. Нажмите **Скачать**.

Настройки сохраняются в `%APPDATA%\\yt-dlp-gui\\settings.json` на Windows.

## Сборка EXE (необязательно)

```bash
python -m pip install pyinstaller
pyinstaller --noconsole --onefile --name yt-dlp-gui app.py
```

Готовый файл появится в папке `dist`. Положите `yt-dlp.exe` рядом с ним.
