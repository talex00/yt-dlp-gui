# yt-dlp GUI

Минималистичное Windows-приложение для скачивания видео и аудио через [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Возможности

- автоматический анализ ссылки после вставки;
- выбор разрешения, FPS, видеокодека и контейнера;
- отображение примерного размера итогового файла;
- выбор аудиопотока, битрейта и формата сохранения;
- автоматическое объединение видео и аудио через FFmpeg;
- опциональное скачивание видео и аудио отдельными файлами;
- скачивание плейлистов;
- скрываемый журнал и индикатор прогресса;
- светлая и тёмная системные темы.

## Скачать

Готовая Windows-версия публикуется в разделе [Releases](https://github.com/talex00/yt-dlp-gui/releases/latest).

Скачайте `yt-dlp-gui.exe` и запустите его. Python не требуется — он встроен в EXE. yt-dlp и FFmpeg скачиваются автоматически при первом запуске в папку `tools` рядом с программой и обновляются при каждом следующем запуске.

## Запуск из исходного кода

Потребуются Python 3.10+, `customtkinter`, а также `yt-dlp` и `ffmpeg` в `PATH` или рядом с `app.py`.

```bash
python -m pip install customtkinter
python app.py
```

## Правовой статус компонентов

Приложение использует сторонние проекты как отдельные исполняемые программы через командную строку и не связывается с их библиотеками напрямую.

- **yt-dlp** распространяется по лицензии [Unlicense](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE).
- **FFmpeg** распространяется на условиях LGPL/GPL в зависимости от конфигурации сборки. Приложение использует [LGPL static build](https://github.com/BtbN/FFmpeg-Builds) от BtbN/FFmpeg-Builds.
- **PyInstaller** разрешает распространять собранные приложения под выбранной автором лицензией при соблюдении лицензий зависимостей.

FFmpeg и yt-dlp принадлежат своим авторам. Проект не связан с ними и не одобрен ими. Названия используются только для описания совместимости.
