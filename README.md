# yt-dlp GUI

Легковесная графическая обертка (GUI) для утилиты [yt-dlp](https://github.com/yt-dlp/yt-dlp), предназначенная для удобного скачивания видео и аудио с YouTube и других видеохостингов.

## 📝 Описание

Данный проект создан как простой и быстрый пользовательский интерфейс для консольного загрузчика [yt-dlp](https://github.com/yt-dlp/yt-dlp). Он позволяет скачивать медиаконтент без необходимости работы через командную строку.

## ✨ Основные возможности

- 🚀 Простой и понятный интерфейс
- 🎥 Скачивание видео в различных качествах и форматах
- 🎵 Извлечение и сохранение аудио
- 📂 Удобный выбор папки для сохранения файлов

## 🛠️ Зависимости

- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — консольная утилита для скачивания медиа.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/talex00/yt-dlp-gui.git
   cd "yt-dlp gui"
   ```

2. Поместите исполняемый файл `yt-dlp.exe` в директорию проекта (или укажите путь к нему в настройках).

*(Дополнительные инструкции по запуску будут добавлены по мере разработки интерфейса).*
